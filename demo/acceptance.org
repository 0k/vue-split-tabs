* Workbench acceptance

The host supplies numbered iframe views and presentation; every layout action
uses the public built package. Tests and recordings share real-input scenarios
in ~scenarios.mjs~. Only recordings add presentation pauses.

| Contract | Named scenario |
|----------+----------------|
| Every tab is renamable; host labels and slot display the edited title | rename label inline and through menu |
| Every close-button mode changes the offered tab controls | option close buttons |
| Library focus border and unfocused keep opacity change live | option focus indication and opacity |
| All four divider sizes; retained layout; fresh working iframe helper | option divider thickness and controller recreation |
| Library-default Alt+Shift click selects; help follows active chords | option pane mouse chords |
| Single-tab bars show and hide live | option one-tab bar |
| Bars stay outside pane marks, dimming and iframe content on every side | external bars stay outside pane marks, dimming and iframe content |
| Right-click menu opens; unchecked items disappear; split item splits | option context menu items and split |
| Disabled layout keys leave shell and iframe content unchanged | option layout keys |
| Display numbered panes with Alt+Shift+Q or Shift+Win+Q, then give pane 2 keyboard focus | display panes with layout keys and Shift Win |
| Reload resets layout, retains every option, stores no layout; freed pane height | option reload resets layout and persists only options |
| Only receiving iframe logs ordered pointer/mouse click events, pane title | iframe ordered mouse events |
| Only focused iframe logs keys; local focus/blur indicator and key flash | iframe keyboard receiver and focus |
| Native two-finger pinch, touch fallback, cancellation and family counts | iframe two-finger pinch and browser cancellation |
| Four-finger hold, live count, shell claim remains at least 1.5 seconds | iframe four-finger hold claim persistence |
| Move folding, log visibility broadcasts and newly loaded iframe settings | iframe log visibility and folding |
| Tap/long press/swipe, two/three-finger vocabulary, cancel, mouse/wheel/key details, bounded log | iframe gesture vocabulary and event details |
| Ctrl+Alt+Shift toggles and drags; Alt+Shift clicks reach content | Workbench pointer chords |
| E/O, divider snap guide, double-press equal thirds | split |
| Rectangular selection, green preview, regroup, refused diagonal | group |
| Four-pane selection becomes a layout tab, return to layout | layout-tab |
| I creates inner bar; middle and bar drops differ | inner-tab |
| Quarter and whole-area drops, spring-loaded hidden tab | drag |
| Four bar sides and side-bar resize | bars |
| Zoom and exact restore | zoom |
| Bin, keyboard close, Undo | close |
| New iframe content is ready before closing by key | close waits for a new pane's iframe to load before its layout key |
| HJKL focus, letter selection, arrow keyboard move | keyboard |
| Native CDP four-finger hold, tap, drag, pinch out/in | touch |
| Same-origin iframe key forwarding; retained iframe state | iframe keys and identity |
| Initial 2x2; generated keys; numbered placeholders | initial layout and host content |
| Fresh storage; blocked external requests; no console errors | every case |
| No stuck ghost, shade, armed drag, guide or cancelled touchmove | every case teardown |
| Browser, context, server and CDP cleanup, also on failure | runner finally blocks |
| Local fonts; fixed viewport; readable keycast; bounded looping GIF | capture assertions and extracted frame review |
| Public dist JS/CSS/frame entry; strict types; package exclusion | demo:build and check artifact smoke |

Run ~npm run demo:test~ for fail-fast acceptance and ~npm run check~ for the
full library and demo gate. ~npm run demo:capture~ regenerates ten GIFs and
the base Workbench still; four review frames per clip remain in the ignored
~demo/.capture/~ directory.
